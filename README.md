# Ali Hassan — Portfolio Vol. 01

A cinematic, editorial web portfolio engineered to showcase high-end video editing and graphic design. 

### Tech Stack
* **Framework:** React + Vite
* **Styling:** Tailwind CSS (v4)
* **Deployment:** Vercel

### Key Features
* **Interactive TV Hero:** Custom scanlines, film grain, and state-driven title cycling.
* **The Reel:** A native-feeling horizontal scroll track with hover-to-play interactions.
* **Duotone Gallery:** A 12-column bento grid featuring dynamic CSS grayscale-to-color hover states.
